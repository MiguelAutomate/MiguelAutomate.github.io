The OWASP Agentic Security Matrix

Vulnerability Taxonomy Directory

ZeroSilence intercepts security patterns mapping directly to the official OWASP Agentic Security Initiative framework. Click on any class to view detailed indicators.

ASI-01 CRITICAL

Goal Hijacking

Malicious code or user instructions passed from external search tools alter the agent's deterministic instruction loop.

AST Capture Indicator:
Matches unchecked downstream model responses passed directly to system instruction updates.
ASI-02 HIGH

Tool Misuse & SSRF

LLMs dynamically generate path-traversal or SSRF parameters inside command line tools without checking input schema bindings.

AST Capture Indicator:
Matches direct execution calls without pydantic models or validation proxy interceptors.
ASI-04 MEDIUM

Agentic Supply Chain

Agents linking to unverified model connection protocols or compromised/untracked MCP (Model Context Protocol) servers.

AST Capture Indicator:
Flagged when open MCP client connections are instantiated without secure JWT access authorization headers.
ASI-08 CRITICAL

Cascading Failures

Infinite looping sequences in which an LLM continues invoking downstream clients despite failing parsing validation schemes.

AST Capture Indicator:
While statements with no loop break conditions calling LLM model contexts or network gateways.
ASI-05 HIGH

Unexpected Code Run

The agent attempts to generate and execute native shell scripts, calling eval or subprocess patterns dynamically.

AST Capture Indicator:
Flagged instantly upon any execution syntax tree match pointing to subprocess modules or python eval declarations.
ASI-10 CRITICAL

Rogue Behavior Drift

Lack of programmatic execution limit constraints allows state-changing agents to drift significantly from targeted outcomes.

AST Capture Indicator:
Vulnerable context logs passed through open downstream schemas without explicit finite state boundary checks.
